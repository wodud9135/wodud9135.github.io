홈페이지 관리

코드를 몰라도 공지·주보·설교를 직접 등록할 수 있습니다.

관리자 화면으로 이동하기

관리 화면은 별도 무료 서비스인 Pages CMS에서 열립니다. GitHub 계정 로그인과 저장소 권한 확인 후 새 글을 작성할 수 있습니다.

STEP 01GitHub 로그인

아래 버튼으로 CMS에 접속하고 교회의 GitHub 계정으로 로그인합니다.

STEP 02새 글 작성

‘공지사항’, ‘주보 등록’, ‘설교 영상’ 중 선택하고 새 글을 만듭니다.

STEP 03저장 및 게시

저장하면 GitHub에 반영되고, 자동 배포 후 홈페이지에 나타납니다.

Pages CMS 관리 화면 열기 ↗
주의: 이 페이지는 관리자 로그인 화면이 아닌 외부 관리 시스템 안내 페이지입니다. 실제 글쓰기 권한은 GitHub 저장소의 권한과 Pages CMS 앱 승인으로 결정됩니다. 홈페이지의 GitHub 저장소 연결을 완료해야 글을 등록할 수 있습니다.
